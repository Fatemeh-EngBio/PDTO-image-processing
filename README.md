# 🧬 PDTO Image Processing

Image processing code for our study on PDTO growth dynamics and Ki67 quantification in EKGel-H and EKGel

This repository includes code used in our study to:

- Quantify Ki67-positive cells from immunofluorescence images  
- Measure organoid circularity and growth over time using area and perimeter measurements  
- Perform time-lapse tracking and visualization  
- Edit and enhance brightfield microscopy images  

---

## 📁 Repository Structure

- `notebooks/` – Jupyter notebooks for analysis and figure generation  
- `data/` – Folder for raw or processed image data (not tracked in repo)  
- `example_images/` – Example input images and annotated outputs  
- `requirements.txt` – Python dependencies needed to run the code
